# Remove TMKD Design

## Goal

Remove every TMKD-specific file, runtime path, configuration option, generated
artifact, and textual reference from the current working tree. Git history is
out of scope and will not be rewritten.

## Changes

- Delete the TMKD criterion, configuration, training scripts, ablation script,
  and generated bytecode files.
- Remove TMKD imports and exports from the configuration and criterion packages.
- Remove the TMKD method choice and command-line options from `main.py`.
- Remove TMKD initialization, tokenizer validation, task-head participation,
  collator setup, and training logic from `distiller.py`.
- Simplify `DualTokenizerCollate` by removing offset mappings and raw-text batch
  fields that exist only for TMKD.
- Reword the historical HeatGeo design verification item so it contains no
  reference to the removed method.

## Compatibility

The remaining distillation methods and their public command-line options stay
unchanged. Shared task-loss and task-head code remains because EMO still uses
it. Shared special-token masks remain because other methods consume them.

## Verification

1. Search file contents and names outside `.git` to confirm the removed method
   has no remaining trace.
2. Compile project Python sources with the existing project `.venv`.
3. Import the configuration and criterion packages and parse CLI help to confirm
   the remaining method registry is valid.
4. Inspect the final diff and Git status to confirm unrelated user files were
   not modified or staged.
