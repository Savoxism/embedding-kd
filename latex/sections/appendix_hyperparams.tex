\label{app:hyper}

We report the core configuration used for RIPPLE and the implementation
choices deferred from Section~\ref{sec:method}. Unless an ablation explicitly
varies one factor, the same configuration is used across all downstream tasks
and teacher--student pairs.

\subsection{Graph and Diffusion Construction}

\paragraph{Entropy-calibrated bandwidth.}
\label{app:entropic-bandwidth}
For a mutual-neighborhood row, let
$p_j(\beta)\propto\exp(\beta c^T_{ij})$, where $\beta=1/\tau_i$. We choose
$\tau_i$ such that
\begin{equation}
\label{eq:entropic-bandwidth}
H(P_i^T)=\log\rho.
\end{equation}
Because
$\mathrm dH_i/\mathrm d\beta=-\beta\operatorname{Var}_{p(\beta)}[c^T_{ij}]$,
the entropy is monotone and the non-degenerate solution is found by bisection.
If row degree $d_i\leq\rho$, we clip the target entropy to
$(1-10^{-3})\log d_i$; degree-one and constant-score rows use the uniform
distribution on their available support.

\paragraph{Scales and sparse profiles.}
\label{app:hyper-ladder}
We set $\tau_1(i)=\tau_i$ and $\tau_r(i)=\sqrt r\,\tau_i$ for broader
scales, with loss weights $\omega_r=1/r$ and $\omega_0=\omega_1$. After each
sparse diffusion step, we retain the smallest support carrying at least
$1-\delta$ mass, with $\delta=0.01$, and renormalize. This rule controls the
stored profile width without introducing an additional scale-specific budget.

\subsection{Candidate and Row Sampling}

The diffusion quota is split as evenly as possible across scales, with the
remainder assigned to sharper scales. At each scale, RIPPLE retains the two
highest-mass entries and draws the remaining quota without replacement in
proportion to teacher mass. Hard negatives are the nearest teacher examples
outside the diffusion pool, prioritizing the same source corpus; the remaining
negatives are sampled uniformly. Candidates are deduplicated, pooled across
anchors, and encoded once as in Eq.~\eqref{eq:pooled-candidates}.

\paragraph{Non-backtracking walks.}
\label{app:hyper-nonbacktracking}
At step $t+1$, the walk samples from $P^T_{j_t}$ conditioned on
$j_{t+1}\neq j_{t-1}$. The exception is a degree-one node, where the previous
edge is the only available transition. Avoiding immediate returns increases
the number of distinct supervised rows at a fixed walk budget. A walk selects
rows only: for every selected row, Eq.~\eqref{eq:lrow} uses its available
dense teacher target rather than a single sampled transition, reducing
gradient variance without changing the expected row objective.

\section{Controlled Experiment Details}
\label{app:experimental-protocols}

\subsection{Core Ablations}
\label{app:ablation-protocol}

All variants in Figure~\ref{fig:core-ablation} use the same student
initialization, optimizer, epochs, seeds, and number of scored anchor--column
pairs. \emph{Batch-local KD} normalizes teacher and student similarities over
co-occurring examples. \emph{Random corpus neighbors} uses a uniformly sampled
corpus support with the same size as the one-step RIPPLE support.
\emph{RIPPLE one-step} uses only $r=1$ and no row loss; \emph{RIPPLE diffusion}
adds $r\in\{2,4\}$; and \emph{Full RIPPLE} additionally enables
$\mathcal L_{\mathrm{row}}$.

The random-graph control applies degree-preserving double-edge swaps to the
undirected teacher graph. Edge weights are recomputed from teacher
similarities at the rewired endpoints, and row bandwidths are recalibrated to
the same perplexity $\rho$. It then uses the same scales, sampler, and row loss
as Full RIPPLE. This preserves graph size, degree sequence, and optimization
while removing teacher-neighbor adjacency.

For a fixed diagnostic anchor set $\mathcal A$, held-out diffusion error is
\begin{equation}
E_r=\frac1{|\mathcal A|}\sum_{i\in\mathcal A}
\mathrm{TV}(g^T_{i,r},g^S_{i,r}),
\qquad r\in\{1,8,16\}.
\end{equation}
Scales $8$ and $16$ are evaluated but never supervised. Full-corpus JS and
student leakage use the same anchors and corpus columns for every variant.

\subsection{Coverage and Sampling Diagnostics}
\label{app:diagnostic-protocols}

\paragraph{Neighborhood breadth.}
We vary only $k\in\{50,100,200,400\}$ and hold the candidate budget, scales,
row weight, optimizer, and schedule fixed. Retained ambient teacher mass is
\begin{equation}
\operatorname{Mass@}k
=\frac1{|\mathcal A|}\sum_{i\in\mathcal A}
g^T_{i,0}(\mathcal M_k^T(i)).
\end{equation}
We also measure teacher--student JS divergence in the fixed teacher-rank bands
$1{:}50$, $51{:}200$, and $201{:}800$, and over the full corpus. The bands do
not change with $k$.

\paragraph{Candidate budget.}
We vary only the number $m$ of candidates. On a fixed checkpoint and probe
batch, sampled-to-full gradient fidelity is
\begin{equation}
\label{eq:gradient-fidelity}
G_m=\cos\!\left(
\nabla_\theta\mathcal L_{\mathrm{diff}}^{(m)},
\nabla_\theta\mathcal L_{\mathrm{diff}}^{(\mathrm{full})}
\right).
\end{equation}
Target mass is measured before renormalization. Step time excludes graph
preprocessing and is averaged after warm-up; peak accelerator memory is reset
immediately before the measured steps. All variants use the same hardware and
software stack.
